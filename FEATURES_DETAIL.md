## 📱 Responsive Breakpoints

- **Mobile:** < 1024px
  - 1 sütun grid
  - Drawer filtreler
  - Kompakt pagination

- **Desktop:** ≥ 1024px
  - 3 sütun grid (lg:grid-cols-3)
  - Sidebar filtreler
  - Geniş pagination

## 🎯 Kullanıcı Akışları

### Filtre Uygulama Akışı (Desktop)

1. Kullanıcı sidebar'dan checkbox seçer
2. `handleFilterChange` tetiklenir
3. Filter state güncellenir
4. `currentPage` 1'e resetlenir
5. `useEffect` API çağrısı tetikler
6. Loading gösterilir
7. Yeni sonuçlar render edilir

### Filtre Uygulama Akışı (Mobile)

1. Kullanıcı "Filtrele" butonuna tıklar
2. Drawer açılır
3. Kullanıcı seçimlerini yapar
4. "Uygula" butonuna tıklar
5. Drawer kapanır
6. Desktop akışı ile aynı devam eder

### Pagination Akışı

1. Kullanıcı sayfa numarasına tıklar
2. `setCurrentPage` çalışır
3. `useEffect` yeni sayfa için API çağrısı tetikler
4. Loading gösterilir
5. Yeni sayfa tarifleri render edilir
6. Scroll otomatik yukarı (optional)

### Favoriler Akışı

1. Kullanıcı ♥️ ikonuna tıklar
2. `handleFavoriteClick` event propagation durdurur
3. `toggleFavorite` async çağrısı yapılır
4. API'ye istek gider
5. Local state güncellenir
6. Icon otomatik değişir (solid/regular)

## 🔄 State Yönetimi

### Component States

```typescript
// Filtre state
filters: {
  ageGroups: string[]
  mealTypes: string[]
  dietTypes: string[]
  specialConditions: string[]
  ingredientSearch: string
}

// Pagination state
currentPage: number
totalPages: number
totalRecipes: number

// UI state
loading: boolean
isFilterDrawerOpen: boolean (mobile only)

// Sorting state
sortBy: 'date' | 'popular' | 'prep_time'

// Data state
recipes: RecipeCard[]
```

### Hooks Kullanımı

- `useChildProfile` - Çocuk profil bilgisi
- `useAgeGroups` - Yaş grupları (SWR ile cache)
- `useMealTypes` - Öğün tipleri (SWR ile cache)
- `useFavorites` - Favoriler yönetimi
- `useState` - Local state
- `useEffect` - API çağrıları
- `useMemo` - Optimize edilmiş hesaplamalar
- `useCallback` - Memoize edilmiş fonksiyonlar

## ⚙️ API İletişimi

### Request Format

```
GET /kg/v1/recipes?
  page=1&
  per_page=12&
  age-group=6-8-ay,9-11-ay&
  meal-type=kahvalti&
  diet-type=glutensiz&
  special-condition=kabizlik-giderici&
  ingredient=avokado&
  orderby=date&
  order=desc
```

### Response Format

## 📈 Performans Optimizasyonları

1. **useMemo:**
   - sortedAgeGroups hesaplaması
   - suitableRecipes/otherRecipes ayırımı

2. **useCallback:**
   - fetchRecipes fonksiyonu
   - getAgeGroupColor fonksiyonu
   - isRecipeSuitableForAge fonksiyonu
   - Filter handler fonksiyonları

3. **Conditional Rendering:**
   - Loading state
   - Empty state
   - Pagination (1'den fazla sayfa varsa)
   - Filter clear button (filtre varsa)

4. **Code Splitting:**
   - Next.js otomatik code splitting
   - Route-based splitting

5. **SWR Caching:**
   - Age groups (useAgeGroups)
   - Meal types (useMealTypes)
